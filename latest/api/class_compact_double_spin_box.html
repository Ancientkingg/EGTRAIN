Detailed Description

Compact when browsing, full precision when editing. Merely visiting a field must not commit its rounded display representation to the canonical model. The wheel changes the value only while the field has keyboard focus. The compact text has six significant digits, except that a value from 1e6 up to 1e15 shows all its integer digits without exponent. While the field is not focused, the tooltip shows the value with its fewest exact digits, after the tooltip of the field, when the compact text is not it.

Detailed Description

The incidents of the selected scenario: a list to pick one, and the fields of the selected incident. An incident is a signal failure or a train breakdown, and the targets it can have depend on that type: a signal or a block, or one occurrence of a service. The choices of targets follow the infrastructure and the services of the document. The scenario whose incidents are shown is the one that the run selection names. Start and end are whole seconds from the start of the run, and the reduced speed is in km/h. The button next to the target combo starts picking the target on the network view; the window does the picking and gives the panel the target.

◆ addIncident() [1/2]

void IncidentPanel::addIncident ( )

Appends an incident with a new unique id and start and end at 0 seconds, and selects it. It has the target of setDefaultTarget(), and the type of that target, when the combo offers it; otherwise it is a signal failure without a target. A scene without a scenario gets the baseline scenario first.

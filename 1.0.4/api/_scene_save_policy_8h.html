bool isInstalledScenePath ( const QString & path,
const QString & applicationDir )
inline

Whether path lies in a folder of installed scenes beside applicationDir (Scenes, ../Resources/Scenes or ../share/EGTRAIN/Scenes), where a scene must not be saved. Only application-relative installed namespaces are protected, not CWD/Scenes. Case-only siblings are deliberately protected even on case-sensitive volumes. An installed-root symlink also protects its target, including an aliased checkout.

Detailed Description

The item data roles of the items of the preview. They identify an item by the ids of the scene model; no model or native pointer is stored, and a click resolves the current data. Roles 0 to 3 belong to the signal decoration (graphics/SignalItemRoles.h).

enum PreviewGraphics::Role

An item data role of the preview.

Enumerator
Kind 

The kind of item: "track", "arc", "connection", "node", "station-node", "station" or "signal".

Id 

The id of the element of the scene model: track, arc, connection, node, station or section.

StationId 

On a station node: the id of its station.

PlatformId 

On a station node: the id of its platform, empty without one.

TrackId 

On a signal head: the id of its track.

Reversed 

On a signal head: true for the head of the reversed direction.

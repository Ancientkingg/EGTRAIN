Source code

Repository

The source code of EGTRAIN, with the history of every change, is in the public repository github.com/Ancientkingg/EGTRAIN. Getting started as a developer says how to build EGTRAIN from it.

Releases

Each release has an archive of the source code that its packages were built from, and a release page with its notes and files.

  • EGTRAIN v1.0.5, 2026-10-24: EGTRAIN-1.0.5-source.tar.gz (release page)

Licence

8// Occupation of a set of resources by a set of trains.
9//
10// Every time is in seconds, every percentage is in percent (the unit of
11// CapacityAnalysisResult::cyclePercentage) and -1.0 marks a value that is not
12// available (the sentinel of CapacityAnalysisResult).
13//
14// The analysis area is only the list AreaCapacityInput::resourceIds of one
15// call. It is not a signalling area, reads no signalling level and is stored
16// nowhere. A resource is a block id as BlockingTimeDiagramInput::blockId holds
17// it. An occupation belongs to a resource when shareBlockingTimeResource is
18// true for the two ids. A composite block id therefore counts for every
19// resource it shares a component with (once in each such row and once in the
20// envelope), so the caller lists plain block ids. A resource id that is itself
21// a composite id matches in the same way, so two rows can count the same
22// occupation. Occupations are not clipped to a time window: the caller chooses
23// the trains of the period and the period is only the denominator.

Detailed Description

The folder in which a file dialog starts. A dialog that is given only a file name starts in the working directory, which is the installation folder when EGTRAIN is started from the Start Menu.

The folder in which the Open Case and Open Case Folder dialogs start: the folder above the open case, or with no case open the example cases when installedScenes is given, otherwise the home folder. On macOS a native open dialog that started in the home folder made macOS ask for access to Desktop, Documents and Downloads before it could be used; one that starts inside the application bundle asks nothing.

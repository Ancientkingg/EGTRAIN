Detailed Description

Writes a recovery copy of a scene while the scene has unsaved edits, through a RecoveryStore.

The first edit after a write arms a single-shot timer. When it fires, the newest scene is written, unless that revision is already on disk. Later edits do not move the timer, so a copy is never more than one interval behind the editing. The interval is 30 seconds, or the value in QEGTRAIN_RECOVERY_INTERVAL_MS when that is a positive whole number of milliseconds.

The write runs on one worker thread, because saving a bundle takes tens of milliseconds for the largest committed scene and longer when the disk or a virus scanner is slow. One job runs at a time. Edits that arrive while a job runs are merged: when it ends, the newest scene is written once. The scene handed over is never modified, so the editing thread needs no lock.

Saving, replacing the scene and returning to the clean state each bump an epoch and remove the copy. A write that is under way cannot be stopped, but its result is dropped and the removal runs after it, so a late write never brings back a copy that a save removed. A write that has not started when the epoch changes does not run.

A failure is reported with writeFailed and never stops the editing: nothing here blocks the caller except scan, adopt, discard and shutdown, which wait for a job that is running. No function throws, prints or logs.

All functions belong to the thread that owns the object, which runs the event loop. Signals are emitted there. The controller holds the store alone: the store is used by one thread at a time and has no static state.

Member Function Documentation

◆ adopt()

RecoveryResult RecoveryController::adopt ( const RecoveryCandidate & candidate)

Takes over the copy of a candidate as the copy of the scene that is now open. It cancels the edits and the removal that wait, like a replacement, but keeps the copy it took over, so a replacement of the previous scene belongs before it. When the store refuses the copy, the copy of the previous scene is still removed, as after a replacement. Refused after shutdown.

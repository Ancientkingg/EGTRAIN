◆ minimumHeadway

double CapacityPairRow::minimumHeadway = -1.0

Largest candidate headway; -1.0 without a shared resource or a valid profile reference (hasSharedConstraint false). It is below 0 when the trains enter the analysed blocks at different blocks and the follower reaches the shared resources later after its reference than the leader leaves them.

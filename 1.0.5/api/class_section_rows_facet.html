Detailed Description

template<typename Item>
class SectionRowsFacet< Item >

A facet over one list of the model whose items have no id and name sections instead, such as the dependencies between blocks. A section is chosen in a combo of the sections of the scene, which writes the model as soon as another section is chosen. The other cells are text. A new item is empty, and a row is named by its first section when it is deleted. Nothing else refers to these items. Item is the type of the items.

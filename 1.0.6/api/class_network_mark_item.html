Detailed Description

The mark of an item of the network on the canvas, a look of its own beside the selection cue of a click (SelectionCueItem), so that both can show at once. It draws a band in kNetworkMarkColor along each stretch of track it is given, a wider band in kNetworkMarkEmphasisColor along each stretch of emphasis, a disc at the start of the first stretch and an arrowhead at the end of the last one when it is directed, a ring around each ring target and a halo around the outline of each halo target. Each part has a dark casing. The sizes are logical pixels on screen, so the mark reads the same at every zoom: the stretches are drawn with cosmetic pens, and the rings, the disc and the arrowhead are sized by the view scale. It is stacked at ZValue, under the tracks, the nodes, the platform bars and the signals, so that it never covers them, takes no mouse input and has an empty shape. The mark reads its targets in sync() and paints only those that are shown. It must not outlive them: the presenter that places it deletes it before the targets, which are deleted only with the whole scene.

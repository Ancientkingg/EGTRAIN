Detailed Description

The dialog of Add from Library: the units of the library under a heading that names the cases that hold them, each with its id, maximum speed, length and number of traction rows, and a tick box that adds a composition of the unit as well. It records the choice and changes nothing; the caller adds the unit after exec() returns.

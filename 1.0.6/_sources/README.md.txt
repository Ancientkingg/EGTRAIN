# Documentation

The documentation has two parts. The manual is for people who install EGTRAIN, run cases and edit them, and the application shows it under **Help > EGTRAIN Manual**. The developer pages explain how the application is built, tested, released and structured.

- [Contents](index.md): every page, grouped by task.
- Manual: start with [Installing EGTRAIN](guides/install.md) and [Getting started](guides/getting-started.md).
- Developers: start with [Getting started as a developer](development/getting-started.md).
- Releases: follow the [Release testing checklist](development/release-testing-checklist.md).

Keep new documentation short, concrete, and current.

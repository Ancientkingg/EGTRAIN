# Inspecting diagrams

Hover near a plotted line or event marker to inspect its nearest **recorded sample**. The tooltip shows that sample's values, units and available station, call or block context. A line between samples is useful for finding a train, but the tooltip does not interpolate a value at the pointer. Filled occupation regions can be inspected inside their boundaries when marked as such by the chart; ordinary closed outlines cannot.

Click a line or marker to select its train. The train filter controls visibility; neither filtering nor navigation changes the underlying CSV data schema. Drag a rectangle to zoom into an area. Two-finger scrolling pans by the supplied pixel distance; an ordinary wheel pans using wheel steps. Ctrl or Command plus wheel zooms around the pointer. Pinch zooms on devices that deliver native or Qt pinch gestures. Use + or - to zoom, arrow keys to pan while the chart has focus, and Home, 0 or Reset zoom to return to the chart's initial bounds. Reset does not remove a train selection or change filters.

Timetable graphs plot planned and simulated station arrival/departure events and dwell; train-path graphs plot continuous simulated trajectory samples. Both use reference-route runtime X in kilometres horizontally and elapsed simulation time vertically, increasing downward from run start (0 s). Choose a reference from routes used in the run. The short graph title identifies the reference route and elapsed-zero origin. The horizontal axis shows the route-coordinate origin and travel direction; a wrapped note below the controls explains the runtime coordinate basis and omitted mapping. These are runtime route coordinates, not authored absolute chainage: scene nodes have X/Y and stations may have `position_km`, but the scene has no explicit chainage datum. The native infrastructure builder copies node X into runtime nodes, the route builder derives route sections from those nodes, and the operations builder retains the resolved stop node in each train. Shared canonical node or station IDs anchor other routes; mapping is limited to monotonic shared-anchor intervals. Unmapped or ambiguous portions are omitted rather than extrapolated. The graph CSV files (`timetable_graph.csv` and `train_path_graph.csv`) contain `Train`, `Reference route`, `Source route`, `Event`, `Station`, `Journey order`, `Call`, `Elapsed time[s]`, `Reference route X[km]`. Missing event times and unavailable projected positions are blank; CSV uses the displayed reference and currently visible trains. Existing timetable table and raw trajectory CSV schemas are unchanged.

Time axes display clock labels without changing the simulation-second values. The diagram title also annotates elapsed zero when the clock starts at a nonzero time. A tooltip is dismissed when the pointer leaves the chart, its series is filtered, the window closes, or the chart is replaced.

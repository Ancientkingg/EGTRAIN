Detailed Description

The passengers of the scene, the journeys of the selected passenger and the ordered legs of the selected journey, and the import of the legacy passenger files. A passenger list, a journey list and a leg list edit the model of the document in place; nothing is copied. The planned departure and arrival windows of a journey are in seconds since midnight, not from the base time. A leg names one occurrence of a service, counted from 1.

Detailed Description

The editor docks at the right of the main window, in one group of tabs: Case Settings, Infrastructure, Rolling Stock Units, Compositions, Services with the stops of the selected service, Scenarios with its Incidents and Entrance delays tabs, and Passengers. It builds the panels and their docks, which the window owns, and connects the panels to each other, to the scene document and, through the Host, to the window.

void EditorDocks::build ( SceneDocument * document,
UserPrompts * prompts,
RunSelection & runSelection,
SceneSession * session )

Builds the panels and their docks, adds the docks to the right of the window, hidden, and connects them. The window calls it once. While it runs, the accessors return what it has built so far, so a Host call in between sees the panels that exist; before it, they return null. The docks do not own the arguments.

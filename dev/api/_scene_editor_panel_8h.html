void restoreListSelection ( QListWidget * list,
const QString & text,
int row )
inline

Selects an entry of a list that was filled again: the one that reads text (see rowOfEntry), or else the entry at row, which was selected before. That is the last entry when the list has become shorter, and the first when none was selected. An empty text selects by the row alone, for a list whose text is not the identity of its entries.

int rowOfEntry ( const QListWidget * list,
const QString & text,
int row )
inline

The row of the entry that reads text in a list that was filled again, or -1 when no entry does or text is empty. The entry at row is preferred when it reads text, so that entries that share their text keep their place. A panel uses it to keep the selected entry selected when the document is replaced by one that lists the entry at another row.

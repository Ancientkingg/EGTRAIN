Detailed Description

The inspector dock, titled after the selected item. It has one form for each kind of item that the user can select on the canvas: a node, an arc, a connection, a signal and a train. Selecting an item shows its form, fills it in and puts a highlight on the item. Before a run the items are the ones of the track preview, which the form fills in from the scene. During and after a run the items belong to the run and the form fills in from them. The panel keeps what is selected, so that the window can mark the station overlay and the train of the selection.

InspectorPanel::InspectorPanel ( QMainWindow * window,

NetworkPresenter & presenter,
Host & host )

Adds the dock to the right side of the window and hides it. The window owns the panel and the dock. The scene is the one that the items are on, and the presenter holds the highlight and the passenger information of the selection. The presenter and the host must stay valid while the panel handles calls and signals.

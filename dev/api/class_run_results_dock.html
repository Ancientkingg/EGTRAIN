Detailed Description

The Run Results dock: the table of the completed run, the lines that say which run it is, the menu that opens the result views, the exports of the table, and the delay baseline. It sits at the bottom of the window and stays hidden until a run has results.

Builds the dock and adds it to the bottom of the window, hidden. The entries of its result view menu open the windows of views. The window owns the widgets; the dock does not own runController, views or host.

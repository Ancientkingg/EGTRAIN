Detailed Description

The changes of a completed run, kept for replay.

What is the same for the whole run (identity, route and direction of each train, capacities, signal, section and platform ids, passenger ids) is stored once in a layout. What changes is stored as the difference to the second before, one record of 8 bytes for each value that changed, with a full copy of the values (a keyframe) at the start of every interval of keyframeSeconds. at() starts from the keyframe of the interval and applies the changes up to the second asked for. Lists and strings that change are stored once in the table of their interval or in the string table.

The positions, speeds and wagon positions of the trains are not recorded. setTrains() hands the history the samples that the completed run holds, shared, and at() derives these fields from them with the arithmetic of buildGuiSimulationSnapshot. Without a train source those fields keep their defaults and the trains are not drawn.

Accounted payload (payloadBytes) counts the capacities of the layout, the string table, the keyframes, changes and lists of every interval, the state of the last second and the part of the train source that the history owns. It does not count allocator bookkeeping, shared_ptr control blocks, container nodes or the snapshots that callers hold. This is not RSS. sharedBytes() reports the samples shared with the completed run apart: the completed run holds them whether or not there is a replay, so they are not in the budget. The budget bounds what record() keeps: when it is reached, the oldest interval is dropped as a whole, and firstTime() and lastTime() tell what is kept.

Threads: record() is called only on the thread that steps the run, while the worker runs, and nothing else touches the history then. The history is moved out of the producer after the worker has joined. setTrains(), at() and every getter are used on the GUI thread only. The train source is immutable, so histories may share it.

◆ record()

void GuiReplayHistory::record ( const std::shared_ptr< const GuiSimulationSnapshot > & snapshot)

Records the state of the second snapshot->timestep. Ignores null, a second that is not later than lastTime() and everything after the history became oversize. A skipped second shows the state of the second before it. Drops the oldest interval while the budget is exceeded. When a count or a static field of the run changes, which no run does, the history starts again at that second and truncated() is true.

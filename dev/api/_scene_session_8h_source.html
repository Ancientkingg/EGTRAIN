29// The scene that the window holds as a file or folder. The session opens, creates and saves scenes, asks what to do
30// with unsaved changes, keeps the list of recent scenes, takes a scene file that is dropped on the window and imports
31// legacy cases. It knows where the scene came from or was last saved, and the diagnostics of its last validation.
32// What replacing or saving a scene changes in the rest of the window, such as the editors, the canvas and the undo
33// history, is done by the window, which the session tells through its Host.

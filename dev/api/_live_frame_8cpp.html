const LiveCommand & command,

The outcome of a command that a client sent, with step as the number of steps that have run. The frame is "applied" when rejectedBecause is null: the run takes the command before its next step. Otherwise it is "rejected" with rejectedBecause as the reason, such as run_ended, no_active_run or queue_full.

Detailed Description

Offers the recovery copies that an earlier run left behind, one row for each, and reports what the user chose. It is a dialog of its own and not a QMessageBox, which the offscreen platform on Windows is not known to show safely. The dialog changes nothing on disk: the caller recovers or discards the copy that selectedIndex names.

Recover and Discard act on the selected row, and Decide Later keeps every copy. Recover is the default button unless the original of the copy may hold newer work, and it is disabled for a copy that this version cannot open. Discard asks for a second click, naming the case, before it finishes. Escape and closing the window give Later.

After the dialog closes, result() holds an Outcome. A caller that discards one copy can remove that row and show the dialog again for the rest.

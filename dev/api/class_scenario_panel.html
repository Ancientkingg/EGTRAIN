Detailed Description

The scenarios of the scene: a list to pick one, the buttons that add, copy, delete, import and export them, and the id, name and description of the selected one. The selected scenario is kept in the run selection, because the next run uses it and the incident and entrance delay editors show its entries. Renaming a scenario rewrites what refers to it, and the default scenario cannot be deleted.

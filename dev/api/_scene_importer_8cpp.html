◆ parseTrainPhysicalSourceFile()

SceneTrainPhysicalSourceResult parseTrainPhysicalSourceFile ( const std::string & path)

Reads a vehicle data file of exactly nine finite numbers in the order of kSceneTrainPhysicalFields, with values the simulation can use. The editor reloads linked files with it. Unlike importLegacyScene, which skips bad rows, it refuses an incomplete file.

◆ parseTrainTractionSourceFile()

SceneTrainTractionSourceResult parseTrainTractionSourceFile ( const std::string & path)

Reads a traction file of rows of five finite numbers, each with v_lower below v_upper, in ascending speed order. Like parseTrainPhysicalSourceFile it refuses an incomplete file.

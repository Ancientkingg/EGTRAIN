Detailed Description

Links the parameter file and the traction file of a rolling stock unit to the files they came from, and takes a changed file into the unit. The files are watched. A change waits until the file has been quiet for 150 ms, and until no run uses the model. A value that was edited by hand and differs from the file is only replaced when the user agrees. The links belong to the session, not to the scene: they are cleared when the document is replaced. Units are named by their id.

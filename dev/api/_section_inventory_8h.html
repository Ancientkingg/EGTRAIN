How a stop of a service binds to the visits of its route.

Enumerator
Resolved 

Bound to a visit after the previous bound stop.

AmbiguousPlatform 

No platform given, and the station has several platforms on the rest of the route.

OffRouteContext 

No platform given, and the station is nowhere on the route.

OutOfOrder 

The station or platform lies on the route only before the previous bound stop.

InvalidPlatform 

The given platform is not on the rest of the route.

UnknownStation 

The station id is unknown.

UnresolvedRoute

◆ analyzeSignallingAreas()

SceneSignallingAnalysis analyzeSignallingAreas ( const SceneModel & scene,
const SceneSectionInventory & inventory )

Which signalling area decides the level of each section. A section belongs to an area when it lies completely inside the area's range on its own track chainage; a track-scoped area applies to the sections of its track and overrides the network-wide areas. When areas of one scope disagree, the first of them decides and the others are listed as conflicts. Areas with a non-finite or empty range or a level outside 0 to 5 take no part.

The direction of a route through these sections in order: 1 forward, -1 reverse, 0 when the joins contradict each other or a pair does not join. A region jump is allowed only in a scene imported from a legacy case. A single section is forward; without joins the chainages of the first and last section decide.

◆ sceneSectionLabel()

std::string sceneSectionLabel ( const SceneSectionDescriptor & section)

What a person reads for a section: "B0 21.010 to 21.310 km" for a block section, or the piece on each track, "B0 21.010 to 21.235, B1 21.252 to 21.450 km", for a switch section. A piece of a switch section whose two ends round to the same value shows that value once. Kilometres have three decimals and a full stop in every locale.

◆ sceneSignalFailureTarget()

std::string sceneSignalFailureTarget ( const SceneModel & scene,
const SceneSectionInventory & inventory,
const std::string & sectionReference )

The target that a signal failure of the section has, as the incident editor offers it: the signal that protects the section when exactly one does and its id names no section, otherwise the block of the section unless a signal has the same id. Empty for a switch section that no signal protects and for a reference that names no section. The reference is a runtime id or a block id.

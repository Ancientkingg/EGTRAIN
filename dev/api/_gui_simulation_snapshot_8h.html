◆ guiSignalRestriction()

int guiSignalRestriction ( int code)
inline

Rank of a section code, lowest is most restrictive. 0 is an occupied or failed section, 751 the section behind it in BACC (red_red, speed limit V_751), 75 caution, 180 approach and 270 clear. A code that is none of these ranks last.

9// The requests that a client sends to the command socket of the live stream (see io/LiveServer.h) and the
10// checks that decide whether the server accepts one. The functions read text and touch no socket, thread
11// or run. No Qt.
12//
13// The commands are the ones that change the timing of a run or end it: they never change the railway,
14// and a run that receives only pause, resume and set_delay_ms gives the same results as one that
15// receives nothing.
16
17// Longest request that is parsed, in bytes, and longest request id.
18constexpr std::size_t kLiveMaxRequestBytes = 4096;
19constexpr std::size_t kLiveMaxRequestIdBytes = 64;
20// Largest delay that set_delay_ms accepts, in milliseconds.
21constexpr int kLiveMaxDelayMs = 1000;

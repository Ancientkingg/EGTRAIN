◆ saveExportInteractive()

QString saveExportInteractive ( QWidget * parent,
telemetry::ExportKind kind,
const QString & title,
const QString & suggestedName,
const telemetry::OperationObservation & operation,
const std::function< std::optional< std::string >()> & bytes,
const ExportWriter & write = {} )

Exports a CSV file or a PNG image, as kind says, through the save dialog of parent: titled title, starting at suggestedName in the folder of dialog_folders::suggestedPath, with a filter for the kind. A path without the suffix of the kind gets it. After the dialog bytes gives the content, or nothing when it cannot be made, which reports an internal failure of the export. write writes the content, or else it is written atomically without provenance; empty content is not written. A failed write reports a failed export. Either failure shows "Export failed" with the path as the person reads it. The window of parent stays in front (KeepInFront). Returns the path that was written, or an empty string when the dialog was cancelled or nothing was written.

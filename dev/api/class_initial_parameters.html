Detailed Description

The options of the process: the command line, the values of the scene that was built last and the live stream.

The process holds one object, the global initial_variables (declared in RollingStock.h). main and the window write it, and buildOperationsFromScene writes the values of the scene into it when a build succeeds. DispatchController::prepareScene copies it into SimulationRun::settings, and the run reads only that copy.

double InitialParameters::times

Length of the run in seconds. Steps t run from 0 while t < times, so with the step of 1 s it is also the number of steps. It is the value of -h when durationOverride is set, and otherwise the duration of the scene once it is built.

The aspect code of the section: 270 clear (only for a section with a level; see level), 180 approach, 75 caution, 751 red-red, 0 occupied or failed (see guiSignalRestriction()).

Signalling level of the section (0 to 5), or kGuiSignalNoLevel. A section without a level keeps its initial code 270, which is not a clear signal.

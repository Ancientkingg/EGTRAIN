Detailed Description

Undo and Redo as a position in a list of whole-scene snapshots. The entry at the position is the live scene. Recording an edit appends a copy and drops the entries after the position, so an edit after Undo abandons the Redo branch. When either limit is exceeded, the oldest entries are dropped; the entry at the position never is.

One position can be marked as saved. The scene is clean exactly when the position is the saved one. Dropping the saved entry, by an edit after undoing past it or by a limit, leaves no saved position, and the scene stays dirty until the next save.

A history always has a root. A new history holds an empty scene as its root until reset. The class has no Qt dependency and is used by one thread at a time; the scenes that it returns are immutable and may be read from other threads.

34// The run of the scene that the window holds. The controller asks the user to review the run, prepares the scene in the
35// simulation, starts the simulation on a worker thread, and stops it on request. It keeps what the run leaves: the
36// status, the run as plain values, the delay baseline, and the clock time at which the run starts. It is the one place
37// in the window that reads the settings of the process (initial_variables). What a run changes in the rest of the
38// window, such as the canvas, the panels and the results dock, is done by the window, which the controller tells
39// through its Host.

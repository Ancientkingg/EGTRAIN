Detailed Description

The route of a train: a sequence of copies of block sections. Positions on a route are X in kilometres along the sections of the route; a train position in metres is X * 1000.

◆ setListInfrastructureElementsForRoute()

void Route::setListInfrastructureElementsForRoute ( const Section & BS)

Appends the infrastructure elements of section BS to InfrastructureElements: its TDS borders, stations and switches, with their route position in metres and the ID of BS. An element with the ID or position of one already listed is left out; a diverging switch edge only when its ID, switch name and connected point all match.

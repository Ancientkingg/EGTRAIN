Detailed Description

The rolling stock units of the scene: a list to pick one, its id, its traction curve, its nine physical values and the references to the files it came from. The number fields keep text that is not a number out of the model.

The physical values, in the order of physicalEdits(): traction unit mass (kg), wagon mass (kg), wagon count, maximum speed (m/s), maximum deceleration (m/s²), frontal area (m²), resistance coefficient (the factor of the speed term of the wagon resistance; no unit is stated), jerk (m/s³) and length (m). A traction curve row holds the lower and upper speed of its band in m/s and the coefficients c0, c1 and c2 of the tractive effort c0 + c1 v + c2 v² in N, with v in m/s.

void TrainUnitPanel::setSourceState ( bool traction,

Shows the state of the source link of the shown unit. traction chooses the traction file over the parameter file. linkedPath is empty when the source is not linked, and status is empty when the link has no status of its own.

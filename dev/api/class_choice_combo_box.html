Detailed Description

Combo box for choice fields in dialogs whose entries can be long imported names. The field can shrink below its text so that a form never needs a horizontal scroll bar, while its size hint still lets the dialog grow to show the whole text. A text wider than the field is drawn with its middle elided. The tooltip is the current text, followed by the tooltip of the current item and the tooltip of the field when they have one, and the popup list is as wide as its widest entry within the screen. The wheel changes the choice only while the field has keyboard focus.

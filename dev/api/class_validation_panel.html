Detailed Description

What the validation of the scene reports, and what the scene and its run made of the loaded data. The table lists the diagnostics, the status label gives their count, and the tree shows the case, its source files and the state of the run. The window puts the table and the tree in docks and the label in its status bar.

◆ setAdvancedDetails()

void ValidationPanel::setAdvancedDetails ( std::function< bool()> enabled)

Tells whether advanced details are on. They add the counts of the warnings and infos to the status, the code, file and path columns to the table, and the format versions, the source files and the parsed objects to the tree. Without it they are off.

◆ setDiagnostics()

void ValidationPanel::setDiagnostics ( std::vector< SceneDiagnostic > * diagnostics)

refresh() writes the diagnostics to this vector, where the window and the other panels read them, and the panel shows them. The panel uses its own until it is given another; null brings its own back. The vector must outlive the panel.

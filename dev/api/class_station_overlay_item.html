Detailed Description

The overlay of a station at its anchor in the scene. It ignores the transformation of the view, so its own geometry is in logical pixels around the anchor. On the network canvas it is a scene decoration: it draws nothing itself and keeps the scene-space picture and name of the station readable (attachArtwork()). Otherwise it draws its own mark and label, which can be placed in the viewport.

void StationOverlayItem::attachArtwork ( QGraphicsPixmapItem * picture,
QGraphicsTextItem * name,
int platformCount )

Links the scene-space pictogram and name of this station. The items stay owned by the scene; both are enlarged about their anchor (bottom centre of the pictogram, top centre of the name) through their item transform, which stays the identity at their scene size. Attach the items to their parents before the first applyViewScale: the transform moves scenePos() of an enlarged item. More platforms rank a station higher when names collide.

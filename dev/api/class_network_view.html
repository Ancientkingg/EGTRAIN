Detailed Description

The view of the network canvas. Items have their positions and sizes in scene units. The view scale, the m11() of transform(), is in logical pixels per scene unit. One logical pixel is as wide as the device pixel ratio of the screen in device pixels. The view fits the track to the viewport and zooms between that Fit scale and maximumZoomRatio() times it. A left drag pans the view.

◆ centerOnExactly()

void NetworkView::centerOnExactly ( const QPointF & scenePos)

Centres the view on a point in scene coordinates to a fraction of a pixel and emits viewportChanged() when the centre moved. The scroll bars take the whole pixels and a translation of the transform the rest. An axis on which the view cannot move that far, at the edge of the scene or with the whole scene in view, is centred to the pixel as centerOn() does.

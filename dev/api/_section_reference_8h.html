The form of one part of a section reference.

Enumerator
Block 

A block id, bare (B0-1) or between two '@' (@B0-1@).

Endpoint 

A block id between two '@' and an offset (@B0-1@-5): one end of a switch transition.

Other 

A block id with other text after its '@' (B0-1@x, @B0-1@x).

◆ parseSectionReferencePart()

std::optional< SectionReferencePart > parseSectionReferencePart ( const std::string & part)

Reads one part of a section reference. A bare block id ends at its first '@', and an id that starts with '@' at the next '@'. An endpoint has an offset after that '@': a number with an optional sign and at most one '.', optionally after a '-' that separates it from the id, as the runtime writes a coordinate (@B0-1@-5, @B0-1@--1.5) and as the legacy importer has always read it (@B0-1@5). Returns nothing for an empty block id and for a part that starts with '@' and has no second '@'.

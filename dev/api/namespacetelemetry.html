Detailed Description

Usage statistics and diagnostic reports: the events, their local queue and the sender. The wire format, the event vocabulary and the HTTP outcomes are in docs/telemetry/README.md, and the batch schema is docs/telemetry/batch-v1.schema.json.

◆ registerEditor()

QAction * telemetry::registerEditor ( QDockWidget * dock,
QMenu * menu,
const CaptureOperation & capture )

Adds a checkable action for dock to menu, owned by dock, whose check mark follows the shown state of the dock. Checking it reveals the dock with revealEditor() and an observation from capture; unchecking hides it. A separate action observes the explicit state before show(), unlike the dock's built-in toggle action whose internal triggered handler runs first.

Detailed Description

template<typename Item>
class ListFacet< Item >

A facet over one list of the model, whose items have an id and are listed in the order of the list. The column of the id is the first. Renaming an item rewrites what refers to it, and an item that others use cannot be deleted (sceneDirectDeleteConsumers). Item is the type of the items, which has a std::string id.

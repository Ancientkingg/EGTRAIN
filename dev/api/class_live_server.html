Queues the hello frame of a run and keeps it, with the id of the run, to publish again when a client sends "describe". The latest hello is kept until the server stops. Returns false and queues nothing when the server is not running, frame is null or the queue is full.

◆ start()

bool LiveServer::start ( int port,
bool commandsEnabled,
const std::filesystem::path & outputDirectory,
std::string * error = nullptr )

Starts the I/O thread and binds the sockets, and returns once they are bound. port is the port of the PUB socket on 127.0.0.1, 0 to 65535; 0 takes a free port. The REP socket, with commandsEnabled, always takes a free port. The endpoints are written to live-endpoint.json in outputDirectory, which is created when it is missing; with commands, the file also holds the token that every request has to carry, and only its owner can read it where the platform supports that. Returns false with the reason in *error when the server is running already, the port is not valid or in use, or the file cannot be written; error may be null. A server that failed to start holds nothing.

◆ stop()

void LiveServer::stop ( )

Sends the frames that are waiting, closes the sockets, ends the I/O thread and removes live-endpoint.json. The close waits at most half a second for a subscriber that does not read. Does nothing when the server is not running.

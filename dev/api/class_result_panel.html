Detailed Description

The side panel of a result window: titled sections in a column that scrolls when it is taller than the window, with a rule between the sections that are shown, and a cursor readout below the column.

QWidget * ResultPanel::addSection ( const QString & title,
QWidget * content,
QWidget * headingWidget = nullptr )

Adds a section below the others: a heading with title and, at its right, headingWidget when given, and content below the heading. A section without a title and without a heading widget has no heading. The panel owns both widgets. Returns the section, which setSectionVisible takes.

◆ keepSectionsWhole()

void ResultPanel::keepSectionsWhole ( )

Makes the panel at least as tall as its sections, so that it does not scroll them itself. A panel in a body that scrolls as a whole, such as the body of a dialog of DialogLayout, needs it, so that the body scrolls to the sections.

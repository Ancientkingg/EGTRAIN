◆ areaCapacityCsv()

std::string areaCapacityCsv ( const AreaCapacityResult & result,
const QString & areaLabel )

The text of area_capacity.csv. Every record has the area and whether the traffic is complete. The record types are summary (period, the cycle of the chain, the legacy envelope; the leader and follower columns hold the first and the cycle-closing train of the chain), resource (one for each resource of the area), pair (one for each pair of adjacent trains of the chain) and note (one for each note). A figure that is not available is an empty field. Empty when the result has no resource row.

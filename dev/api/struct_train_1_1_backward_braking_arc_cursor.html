Detailed Description

Finds the arc of the route under a head position in metres for a walk against the direction of travel, continuing from the previous lookup, with the result of brakingArc.

The scan of brakingArc returns the first arc that holds the head. While the arcs up to the arc of the last lookup are ordered (each starts at or after the end of the one before it and does not end before it starts), that is the only arc of them that holds the head, so the cursor moves back over them. Otherwise, and when none of them holds the head, it scans from the first section again.

◆ incidentTargetChoices()

IncidentTargetChoices incidentTargetChoices ( const SceneModel & model,
const SceneIncident * incident,
double occurrenceDuration )

The targets that incident can have in model, with the one it has; only "Choose target" without an incident. A signal failure is offered the signals and the blocks, named by the labels of their sections. A breakdown is offered all runs of its service when it names no run, then each run of each service in turn up to RuntimeLimits::kMaxExpandedTrains runs in all, counted over occurrenceDuration seconds, and then the run past that limit that the incident names. A target that the scene does not have is listed as missing. Entries that read the same name their service and run.

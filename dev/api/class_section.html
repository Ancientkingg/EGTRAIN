Detailed Description

A block section. RunInfrastructure::sections holds the sections of the scene and the sections derived at switches, and a Route holds copies of them, reversed for a reversed route. X values are kilometres.

Constructor & Destructor Documentation

◆ Section()

Section::Section ( )

An empty section with code 270, state Green and no signalling level (kSignallingLevelUnset). The track line IDs and the ETCS3 braking points are -1.

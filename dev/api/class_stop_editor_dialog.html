Detailed Description

The dialog that adds a stop to a timetable or edits one: the insert position when it adds, the station, the platform, the planned time display, the planned arrival and departure and the minimum dwell. It works on its own copies of the scene and of the service, which it does not change, and holds nothing of a document. OK takes the stop only when validateStopDraft() finds no problem; otherwise the dialog shows the problem and focuses its field. The station and the platform offered are those that the route reaches there, and a line under them says how the stop resolves.

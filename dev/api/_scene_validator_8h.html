◆ validateRunnableScene()

std::vector< SceneDiagnostic > validateRunnableScene ( const SceneModel & scene,
const SceneRunSelection & selectedOccurrences = {},
std::optional< double > effectiveDurationOverride = std::nullopt )

Validates the model as validateScene does, plus the minimum complete model needed by a runnable simulation and the capacities of the runtime. A non-empty selectedOccurrences counts only those occurrences against the train capacity. effectiveDurationOverride, in seconds, replaces the duration of the scene settings.

◆ validateSceneStructure()

std::vector< SceneDiagnostic > validateSceneStructure ( const std::string & sceneDir)

Validates only the scene files and JSON shape: the diagnostics of loadScene. No cross-file semantic checks are performed, so callers can show useful parse diagnostics for an incomplete historical scene without a cascade of reference errors.

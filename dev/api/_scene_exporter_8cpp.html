◆ LegacyInputKind

enum class LegacyInputKind
strong

What the importer accepts as an input of a legacy case.

Enumerator
Entry 

Any entry, which the importer opens by its name.

File 

A regular file in a folder that the importer lists.

Folder 

A track folder.

Sidecar 

The area sidecar, which the publish removes first even when the export writes it again, so that an old sidecar never decides the areas of new track files.

std::vector< CapacityAnalysisScope > capacityStretchesFrom ( const CompletedRunData & data,
int routeIndex,
const std::vector< std::string > & occurrenceIds )

The sections of a route that the trains occurrenceIds share, in route order: each run of consecutive blocks of the route that every one of the trains occupies as capacityInputFrom needs, ended by a block that one of them does not occupy or by the end of the route. Each is a scope with the blocks of its run and the occurrence ids as given. None when the route does not exist, when there is no id, when an id names no train of the run or when no block is shared by all of them.

◆ chooseCapacityAnalysisScope()

bool chooseCapacityAnalysisScope ( QWidget * parent,
const CompletedRunData & run,
CapacityAnalysisScope & scope )

Asks for a route, a period, the occurrences to analyse in order, the occurrence that closes the cycle and one of the sections that capacityStretchesFrom gives for the checked occurrences. The longest section is selected; after a change of the checked occurrences or of their order, the section that starts at the block where the selected one started stays selected when there is one. It opens on the route of the scope when the run has it, with the occurrences of the scope checked when it names some, else on the first route. Otherwise, and on a route chosen in the dialog, the trains of the first block of the route that two or more trains occupy are checked. On accept the scope holds the choice. False when the dialog is cancelled or the run has no route.

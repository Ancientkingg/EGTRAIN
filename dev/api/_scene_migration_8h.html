SceneMigrationResult migrateSceneCopy ( const std::string & sourcePath,
const std::string & destinationPath,
const SceneMigrationRegistry & registry = productionSceneMigrationRegistry() )

Upgrades a copy of an older scene directory or bundle at sourcePath and writes it to destinationPath, as a bundle when that path ends in .egscene. The source is not changed. The copy is written only when the upgraded scene loads and validates without errors.

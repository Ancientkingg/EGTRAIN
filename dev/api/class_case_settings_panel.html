Detailed Description

The six scene-level values: name, description, base time (HH:MM:SS), duration and buffer time in seconds and recovery time in percent. Opening the panel never changes the model, and every edit takes the same path through commit().

◆ commit()

void CaseSettingsPanel::commit ( )

Takes the values of the fields into the document, when one differs from what the field shows of the model, as one change "Edit case settings". The fields call it when editing finishes. A stored number outside the range of its field, which the field shows at the nearest limit, stays as it is until the user edits it. A duration, buffer or recovery value that is set this way counts as given in the scene from then on.

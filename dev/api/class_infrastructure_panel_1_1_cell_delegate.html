Detailed Description

The delegate of the table. It knows the editor that it has open on a cell. The widgets that facets put in cells with setCellWidget are not its editors.

Member Function Documentation

◆ commitOpenEditor()

void InfrastructurePanel::CellDelegate::commitOpenEditor ( )
inline

Takes the text of the open editor into its cell and closes the editor, as leaving it does: the view writes the text with setModelData(), and the table tells itemChanged() when it differs. Does nothing without an open editor.

10// Hands a file that the system asked a second process to open to the instance that already
11// runs. The running instance listens on a local socket (a named pipe on Windows). A second
12// process that has only a file to open sends the path, waits for the answer and ends; the
13// running instance emits openRequested.
14//
15// A file that the system opens with the process itself, as Finder does on macOS, arrives as a
16// QFileOpenEvent of the application, whether the process starts for the file or already runs.
17// A relay that is made while the application exists turns it into the same openRequested and
18// keeps it until something is connected to the signal.
19//
20// A request names the application folder of the sender, and an instance accepts only requests
21// that name its own folder, so a copy of EGTRAIN never receives the files of another copy.

Detailed Description

Prepares a scene into the run of the process and runs it.

The process has one controller, the global simulation, and every controller works on defaultRun(). prepareScene, resetState, the live stream functions and the reading of the results are called on the GUI thread, or on the main thread of a run without a window, while no run is going on. runSimulation runs on the thread of a SimulationWorker in the window and on the main thread without a window. The signals of a run are emitted on the thread of the run.

◆ prepareScene()

std::vector< SceneDiagnostic > DispatchController::prepareScene ( const SceneModel & scene,
const std::string & selectedScenarioId = {},
const SceneRunSelection & selectedOccurrences = {} )

Builds the run of the scene apart from the run of the controller and puts it in its place when the scene is ready. A scene that is not ready ends the run that was there: the controller then holds a new run.

selectedScenarioId names the scenario whose incidents and delays apply; empty takes the default scenario of the scene, or its first. selectedOccurrences lists the service occurrences that run; empty runs them all. The run takes a copy of initial_variables as its settings, writes to its output folder, which is made if needed, and starts without the files that a run appends to. Returns the diagnostics of the validation and the builders, and the error run.output.folder when the output folder cannot be made.

◆ runSimulation()

void DispatchController::runSimulation ( )

Runs the prepared run on the calling thread: the steps, then the energy, the timetable points, the delay statistics, the blocking times and the output files. A stop is checked between these stages and ends the run there. A run without trains is not run: it emits executionRejected and logs an error. The control of the run is that of SimulationWorker::active(), or a new one when there is no worker. An exception ends the run: its text goes to lastRunError() and the log, and executionFailed is emitted. The function itself does not throw.

◆ startLive()

bool DispatchController::startLive ( int port,
int every,
bool commands,
const std::filesystem::path & endpointDirectory,
std::string * error = nullptr )

Starts the live stream (see io/LiveServer.h): every run that follows publishes a hello frame, a state frame for every every-th step and the events of its end, and the stream outlives the runs. The endpoint file goes to endpointDirectory. With commands, the commands that clients send (pause, resume, stop and set_delay_ms) are handed to the control of the run at the top of each step, also while the run is paused, and each is reported as an applied or rejected event. Call this before prepareScene and while no run is going on. Returns false with the reason in *error when the server cannot start. A process that never calls it has no server, no thread and no socket, and its runs build nothing for the stream. A port of 0 takes a free port, and an every below 1 counts as 1.

enum class SceneCompatibilityClass
strong

How the version of a scene relates to the versions this application reads.

Enumerator
Current 

The current schema and, for a bundle, the current bundle layout.

OlderMigratable 

Older, and the migration registry has a path to the current version.

OlderUnsupported 

Older without a migration path, or in the unsupported draft layout.

Newer 

A newer schema or bundle layout.

Malformed 

The version could not be read.

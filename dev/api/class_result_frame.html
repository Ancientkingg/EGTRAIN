Detailed Description

The frame of a result window. A splitter holds the main widget, with a header row above it, and the panel beside both. The header shows the context of the window in one line at the left and tool buttons at the right, the last of which shows and hides the panel. The panel is 260 px wide, or 200 px while the window is narrower than 1000 px, until the user drags the splitter, which stops at 200 px; the main widget takes the rest, and the splitter cannot collapse either of them.

void ResultFrame::installInDialog ( QDialog & dialog,
const QString & heading,
QDialogButtonBox * buttons )

Lays out dialog with DialogLayout::install, with the frame as its body from edge to edge and buttons as the footer, which keeps the margins of the dialog. The heading becomes the window title. The panel keeps its sections whole, so that the body scrolls when the window is shorter than the panel.

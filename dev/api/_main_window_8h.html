◆ crashNoteFolder()

QString crashNoteFolder ( )

The folder for crash notes, or an empty string when this run keeps none. QEGTRAIN_CRASH_DIR names a folder for any run. Otherwise a scripted run and a run on the offscreen or minimal platform keep none, so that they never meet the notes of a user, and a normal run keeps them in AppLocalDataLocation/Crashes. Call it once the application exists.

Detailed Description

The windows that show the completed run: the per-train charts, the route and timetable diagrams, the delay charts, the blocking-time diagram, and the capacity analyses. Each slot opens one window over the main window and reads the run of the RunController. Without results a slot opens nothing; all but the train paths and the timetable graph say so in the status bar.

QString releaseNotesMarkdown ( QString notes)
inline

Release notes as the Markdown that a message box shows. Markdown joins the lines of a paragraph, so a line that is followed by another line gets a hard break, except inside a fenced block. GitHub gives the notes with CRLF line ends.

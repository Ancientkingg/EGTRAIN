Detailed Description

The widget of one scene editor dock. A panel shows the model of its SceneDocument, changes it with SceneDocument::edit, which can refuse while a run uses the scene, and then emits changed(). The window creates the dock and puts the panel in it. The panel does not own the document. The base keeps what every panel has: the document with its signals, the prompts, the run selection and the time over which occurrences are counted. A panel that does not need one of them does not use it.

◆ takePendingText()

void SceneEditorPanel::takePendingText ( )
inlineprotected

Takes the text that is still being typed in the panel into the document, before documentChanged() writes the stored values over the fields. Only for kinds that the panel never edits itself: the change is then an edit of another panel, and the text is taken as an edit of its own after it. The signals of the panel are blocked meanwhile, because the other panel is still in the middle of its edit and the window answers changed() by taking the text of every panel, that one too. The window validates both edits when the other panel emits changed().

52// Draws the track preview and the items of a run on the network canvas and keeps track of the items on
53// it. The scene owns every item; the lists, maps and pointers below only observe them and are never
54// used to delete one. They are public until all the code that fills them is in this class.
55//
56// clear() deletes every item of the scene and then forgets all the pointers to them. A pointer
57// that stays after the scene is cleared would dangle, so the registries belong with the code that
58// clears the scene.

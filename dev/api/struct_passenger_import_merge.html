Detailed Description

What an import of legacy passengers adds to a scene. A passenger is rejected when its id is empty or the scene or an earlier accepted passenger of the import has it, or when a journey or leg id of it is empty, repeated inside it, or one that the scene or an earlier accepted passenger has. The ids of a rejected passenger stay free.

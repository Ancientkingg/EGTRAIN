Detailed Description

The stop, pause and step delay of one run, and a bounded queue of commands for them. Every run has one, also a run without a window. No Qt.

The request functions, the readers and submit can be called from any thread. beginStep and applyQueuedCommands are called by the thread that runs the steps only.

A command waits in the queue until the run reaches the top of a step. There beginStep takes every waiting command and applies it in the order of the submits, then checks pause, stop and the delay. No command takes effect in the middle of a step.

◆ beginStep()

bool RunControl::beginStep ( const std::function< void()> & fetchCommands = {})

The top of a step. Applies the waiting commands, waits while the run is paused (and applies the commands that arrive meanwhile), then sleeps for the step delay. Returns false when the run is to stop; the delay is not waited for then.

fetchCommands, when it is given, is called before the waiting commands are applied, also after each wait of a pause. It lets the owner of the run submit commands that come from another source, which a paused run could not otherwise take.

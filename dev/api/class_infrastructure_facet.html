Detailed Description

One kind of entity that the infrastructure panel lists, such as the tracks. The panel owns the facet combo, the table, the selection and the facets. A facet knows the columns of the table, the rows that show the entities of the scene, and what an edited cell, an addition and a deletion do to the model of the panel's document. It changes the model only through InfrastructurePanel::edit or InfrastructurePanel::editInPlace, which refuse while the document is not open for edits, and when it refuses an edit it calls InfrastructurePanel::refuseEdit. The panel calls key(), capabilities(), columns(), fillRows(), selectionId() and commitPendingEdits() at any time, and commitCell(), add(), remove(), insert(), move(), addSection(), removeSection() and moveSection() only while the scene is loaded and open for edits. A widget that a facet puts in the table can still change while the scene is closed for edits.

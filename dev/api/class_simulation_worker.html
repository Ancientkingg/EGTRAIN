Detailed Description

Runs one simulation of a DispatchController on the thread that the worker lives on, and holds the RunControl of that run.

The window makes a new worker for each run, moves it to a new QThread and calls run() when the thread starts. The worker constructed last is the active one, through which DispatchController::runSimulation finds the control of its run.

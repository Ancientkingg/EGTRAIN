Enumeration Type Documentation

◆ SignallingLevel

enum class SignallingLevel : int
strong

The signalling levels. The numbers are the values stored in signalling.json and in Section::SignallingLevel. Their display labels are in scene/SignallingLevelNames.h.

Enumerator
Atb 

Level 0, fixed block, labelled ATB.

EtcsLevel1 

Level 1, fixed block, labelled ETCS Level 1.

EtcsLevel2 

Level 2, fixed block, labelled ETCS Level 2.

EtcsLevel3 

Level 3, moving block, labelled ETCS Level 3.

VirtualCoupling 

Level 4, moving block in which a train can follow the train ahead.

Bacc 

Level 5, fixed block, labelled BACC.

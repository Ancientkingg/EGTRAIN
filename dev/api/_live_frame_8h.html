Detailed Description

Frames of the live contract, built from the immutable snapshot of a step. The members of each frame and their units are described in docs/live/frame-v1.schema.json, and the contract in docs/architecture/external-sharing.md. Times are in seconds, positions in metres, the x coordinate in kilometres and speeds in m/s. A value that the snapshot does not hold, such as the position of a train that has not entered, is null in the frame and never a sentinel: the -1 that Train::trainXPosition gives for a head in no block section becomes null, and so does a number that is not finite. No Qt.

The functions only build JSON and keep no state. DispatchController calls them on the thread that runs the steps. Every frame carries seq, the position of the frame in the run, counted from 0 across all frames; the caller assigns it.

◆ LiveEvent

enum class LiveEvent
strong

A change in the life of a run that an event frame reports.

Enumerator
StepsFinished 

"steps_finished": the step loop has ended and the positions are final. Result files may still be written.

RunCompleted 

"run_finished" with status "completed": the stages of the run have ended. Not every result file is written yet.

RunCancelled 

"run_finished" with status "cancelled": a stop was requested, and the stages after it are skipped.

The outcome of a command that a client sent, with step as the number of steps that have run. The frame is "applied" when rejectedBecause is null: the run takes the command before its next step. Otherwise it is "rejected" with rejectedBecause as the reason, such as run_ended, no_active_run or queue_full.

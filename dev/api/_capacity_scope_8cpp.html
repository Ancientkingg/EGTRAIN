bool chooseCapacityAnalysisScope ( QWidget * parent,
const CompletedRunData & run,
CapacityAnalysisScope & scope )

Asks for a route, a range of its blocks, a period, the occurrences to analyse in order and the occurrence that closes the cycle. It opens on the route and section of the scope when the run has them, else on the whole first route. On accept the scope holds the choice. False when the dialog is cancelled or the run has no route.

Detailed Description

Sends requests. A reply is a child of its transport; the caller releases it with deleteLater().

◆ post()

virtual HttpReply * HttpTransport::post ( const HttpRequest & )
inlinevirtual

Sends request.body with a POST. A redirect is not followed: its reply is the reply of the post, without an error. The request carries no cookie and no credentials. The default transport cannot post and returns nullptr.

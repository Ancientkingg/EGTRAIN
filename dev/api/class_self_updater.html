Detailed Description

Downloads the update manifest and the package of a release, prepares the package on a worker thread and starts the update helper that installs it.

◆ removeUpdateBackup()

void SelfUpdater::removeUpdateBackup ( )
static

Removes the backup of the previous installation that an update in place keeps next to the installation: the folder or file named like currentPath plus ".egtrain-old", never a symbolic link or a junction. It does nothing for a copy that updates with the installer, which has no backup, and while a staging folder is next to the installation. Failures are ignored. The update helper needs the backup until its observation window ends, so the application calls this kSecondSweepDelayMs after its start (update/UpdateTiming.h), after cleanupStaleStaging, and never in the sweep at its start.

◆ restart()

bool SelfUpdater::restart ( )

Starts the update helper of an update that is ready. The helper waits for this process to end, installs the update and starts the application again. Returns false when no update is ready. Returns false and removes the staged update when the helper could not be started.

14// The frames of a completed run, kept for replay.
15//
16// What is the same for the whole run (identity and static data of trains, signal and section
17// ids, platforms) is stored once in a layout. A frame stores only flat arrays of the values that
18// change. Strings that vary (passengers, virtual coupling messages) are stored once in a string
19// table and referred to by number. atOrBefore() rebuilds an ordinary snapshot from the compact
20// form. A frame that is still in use, and the last one handed out, is not rebuilt.
21//
22// Accounted payload bounds include vector and string capacities, but not allocator
23// bookkeeping, shared_ptr control blocks or container-node overhead. This is not RSS. When the
24// budget is reached the oldest frames are dropped; firstTime() and lastTime() tell what is kept.
25//
26// record() is called on the simulation thread. The history is read on the GUI thread after it
27// has been moved out of the producer, so no member is shared between threads.

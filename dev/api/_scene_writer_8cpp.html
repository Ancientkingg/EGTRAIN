◆ saveScene()

SceneSaveResult saveScene ( const SceneModel & scene,
const std::string & sceneDir )

Writes the scene files into a private directory next to sceneDir, loads them back, and then renames the directory into place. On failure the previous directory stays as it was. views.json and passengers.json are written only when the scene has views or passengers.

Detailed Description

The infrastructure of the scene: a combo on top to pick the kind of entity, a sentence about the kind (infrastructureGuidanceText), a table with one row for each entity of that kind, and under the table the buttons that add and delete one. The kinds are the facets: tracks, nodes, arcs, blocks, connections, stations, platforms, signals, signalling areas, routes, block dependencies, single-track restrictions and station boundaries. What a kind lists and how it is edited is up to its InfrastructureFacet; a kind without one lists nothing. The facet also says which other controls it uses (InfrastructureFacet::capabilities): a filter on the track under the combo, which blocks use, buttons that insert and move an entity, which blocks use too, and the heading "Route sections" with the list of the sections of the selected route and the buttons that change it, below the table in a splitter, which routes use. The buttons call the facet that is chosen, only when it has their capability and only while the scene can be edited.

◆ edit()

bool InfrastructurePanel::edit ( const QString & label,
const std::function< void(SceneModel &)> & apply )

Changes the infrastructure of the document with apply as one edit under label (SceneDocument::edit), tells changed() and lists the entities again. While the document is not open for edits nothing changes, nothing is told and the result is false. A facet decides before the call whether there is a change, so that an edit that changes nothing adds no undo step.

◆ afterRunStopped()

virtual bool SceneSession::Host::afterRunStopped ( std::function< void()> action)
pure virtual

With a simulation running: asks it to stop, keeps action for the moment it has stopped and returns true. The last action replaces an earlier one. Without a simulation it returns false and the caller acts at once.

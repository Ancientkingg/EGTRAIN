◆ buildLoadedDataSummary()

std::vector< SceneLoadedData > buildLoadedDataSummary ( const SceneModel & scene,
const std::set< std::string > & files,
const std::vector< SceneDiagnostic > & diagnostics )

The Loaded Data summary of a scene: a row for each scene file with the parts of the scene below it. files names the scene files that are present; a required file that is not is Invalid and an optional one MissingOptional. Each of these rows ends with a validation row that counts the diagnostics of its file (the scene row also counts those of no file or of a file without a row), and the row becomes Invalid or Warning when one of them is an error or a warning.

Detailed Description

Raises the window of a widget and makes it active again when the guard ends, so that a result window stays in front after the save dialog of an export and the messages that follow it, saved or cancelled. On macOS the save dialog runs application modal, and when it closes AppKit gives the key window to the main window. A result window is a dialog of the main window, which Qt makes a panel that cannot become the main window of AppKit, so it would drop behind.

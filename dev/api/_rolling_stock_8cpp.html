◆ trainXPositionOf()

double trainXPositionOf ( const Train & train,
int t,
int wagon = 0 )

The X position in kilometres of a point of the train at step t, as Train::trainXPosition gives it, for a train that is read and not changed. The point lies wagon * train_length / (number_of_wagons + 1) metres behind the head, so wagon 0 is the head and wagon number_of_wagons + 1 the tail. Returns -1 when the point is on no section of the route.

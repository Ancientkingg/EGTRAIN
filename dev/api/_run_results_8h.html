◆ TimetableValueStatus

enum class TimetableValueStatus
strong

Whether the planned and the simulated time of an arrival or departure exist. The delay is available only with Available.

Enumerator
Available 

Both times exist.

NoPlan 

Only the simulated time exists.

NotReached 

Only the planned time exists.

NoPlanAndNotReached 

Neither time exists.

16// The infrastructure and the routes that the scene builder makes: the tracks, connections and stations of the network, its block
17// sections and detection sections, the single-track data and the routes of the trains.
18//
19// The arrays of tracks, connections and stations have a fixed number of elements that nothing resizes, so the elements of a built
20// infrastructure and the buffers that they hold stay where they are until the infrastructure is reset or replaced. A build that fails
21// puts the earlier infrastructure back as it was. The canvas keeps Node* and Arc* into the tracks and Connections* into the

66// The state that one simulation run builds up and that the next run must not see.
67//
68// The routines of the simulation library take the run that they work on as a parameter, and the
69// member functions of a train reach it through Train::run_, which the operations builder sets.
70//
71// The process has one run, defaultRun(). It has a fixed address, so reset() clears every member in
72// place. The window reads the run through DispatchController::run(), which gives the same run; a test
73// that calls the builders itself passes it defaultRun() or a run of its own. DispatchController::prepareScene
74// builds a run apart from it and puts the finished run in its place with adopt(). A member that is added
75// here must be cleared in reset(), or in resetInfrastructure() when it belongs to the
76// infrastructure, and a member that points at another member needs a line in adopt().
77struct SimulationRun {
78 // The settings of the run: a copy of initial_variables that DispatchController::prepareScene takes once the scene is built. It holds
79 // the output folder and the buffer time and running time recovery of the run. A change to initial_variables after that does not
80 // reach the run.
81 InitialParameters settings{0};
82
83 // Block sections that trains occupy and the sections connected to them. The signalling routines fill
84 // the lists during a step and the step clears them.
85 std::list<std::string> blocksOccupied;

87 // Movement authorities of the current step: those of levels 3 and 4, and the failed signals at every level.
88 std::list<MovementAuthority> etcsMa;

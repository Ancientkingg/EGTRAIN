◆ sceneDirectDeleteConsumers()

std::vector< std::string > sceneDirectDeleteConsumers ( const SceneModel & model,
const std::string & facet,
const std::string & id,
const std::string & scope = {} )

One description per use of the entity id, in the order found, for the message that blocks a delete. Empty when nothing uses it. facet is an infrastructure table ("tracks", "nodes", "blocks", "connections", "stations", "platforms", "signals", "routes") or one of "train_unit", "composition" and "service". The other infrastructure tables are not used by anything. scope is the id of the station that holds a platform.

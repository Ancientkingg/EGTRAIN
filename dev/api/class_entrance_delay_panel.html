Detailed Description

The entrance delays of the selected scenario: a list to pick one, and the fields of the selected delay, which holds a train back before it enters the network. A delay names one occurrence of a service (counted from 1), the station at which the train is held and the delay in seconds. The choices of occurrences and stations follow the services of the document: a station is offered when the first stop of the service there has a planned departure. The scenario whose delays are shown is the one that the run selection names.

void EntranceDelayPanel::addEntranceDelay ( )

Detailed Description

An end of authority for levels 3 and 4, and for a failed signal at every level. SimulationRun::etcsMa holds the authorities of the current step. Positions are metres.

◆ type

std::string MovementAuthority::type

What the authority stands for: "TrainEnd" (an end of a train), "DivergingSwitchOccupied" (a diverging switch a train is on) or "SignalFailure" (a failed signal or a held single-track section). "None" by default.

◆ typePart

std::string MovementAuthority::typePart

Which end of the train it is: "Front" or "Tale" (the code spells the rear end this way). A signal failure has "Front". "None" by default.

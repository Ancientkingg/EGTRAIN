◆ formatPlannedTime()

std::string formatPlannedTime ( std::optional< double > value,
bool clock,
long long baseOffsetSeconds )

Formats a planned time, value seconds after the base time baseOffsetSeconds (seconds since midnight). An empty value gives "". A non-finite value, or a base outside [0, 86400), gives "Invalid". When clock is false the result is value in seconds; when it is true, the time of day "HH:MM:SS" of base plus value, preceded by "+Nd " or "-Nd " on another day than the base. Seconds keep their fraction at full precision without trailing zeros, and the decimal point does not depend on the locale.

std::string formatSimTime ( long long simSeconds,

Formats a simulation time as a time of day "HH:MM:SS". simSeconds is seconds since the start of the run, and baseOffsetSeconds the start of the run in seconds since midnight. A negative sum gives "00:00:00", and the result wraps at 24 h.

◆ parsePlannedTime()

bool parsePlannedTime ( const std::string & text,
bool clock,
long long baseOffsetSeconds,
std::optional< double > & value )

Reads a planned time in the form of formatPlannedTime() into value, in seconds after the base. Empty text clears value. The clock form accepts an optional "+Nd " prefix but no negative day, hours up to 23, minutes up to 59 and seconds below 60. When text equals the form of the current value, value keeps its exact stored value. Returns false and leaves value unchanged when the text is malformed, the result is negative or the base is outside [0, 86400).

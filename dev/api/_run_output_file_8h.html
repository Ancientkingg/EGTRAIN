Detailed Description

The files that a run writes to its output folder. Each writer opens its file with openRunOutputFile and ends it with closeRunOutputFile, so a file that cannot be written throws "Cannot write <path>: <reason>", which ends the run as failed (DispatchController::runSimulation). A path is UTF-8, as the output folder of the settings of a run is.

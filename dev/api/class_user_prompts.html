Detailed Description

The messages and questions that the editors put to the user. A panel gets one from the window, and a test replaces the virtual functions to answer without a dialog.

virtual void UserPrompts::showError ( QWidget * parent,

const QString & message,
bool warningIcon = false )

An error message in a modal box, with a warning icon instead of the critical one when warningIcon is set. In a suppressed run it writes "QEGTRAIN_DIALOG_SUPPRESSED: title: message" to stderr instead. The title and the message also go to the log, at error level in the category app.ui.

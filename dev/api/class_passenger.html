Detailed Description

A passenger with the journeys it makes during the run. Times are seconds since midnight. The current state names the journey, leg, station and train of the moment; each is "None" when it does not apply.

◆ checkJourneyStart()

void Passenger::checkJourneyStart ( int t)

While the passenger is outside the network, starts each uncompleted journey whose drawn departure time has come and puts the passenger on the departure platform of its first leg. t is the time in seconds since midnight.

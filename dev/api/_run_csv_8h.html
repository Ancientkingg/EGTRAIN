◆ CompletedRunCsv

using CompletedRunCsv = std::string (*)(const CompletedRunData& data, const QStringList& visibleTrainIds)

The CSV provider of a result window: it shares the run and gives one export of it for the trains that the window shows, whatever the simulation holds by then.

The blocking-time CSV: the envelopes of the visible trains in segments, their planned stop references, the recorded trajectory rows, the envelopes that could not be projected and one row for each section in extents. Every row has the columns of blockingTimeCsvHeader(); the geo X columns map the positions through the PositionScale of extents.

Detailed Description

Edits an optional "#RRGGBB" colour text: a swatch, a Choose button that opens the colour dialog and a Default button that removes the colour. An empty text means the default. A stored text that is not a colour is shown as it is and kept until the user chooses a colour or presses Default.

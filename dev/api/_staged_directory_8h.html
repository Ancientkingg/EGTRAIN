StagedDirectory & staged )
inline

Creates an empty directory in parent, named like uniqueSiblingPath names a path, and sets staged.path to it. With ownerOnly the directory is limited to its owner. The staged directory becomes the published directory, so its mode is part of the result: a save asks for owner-only, an import and an export keep the default mode.

◆ publishStagedDirectory()

StagedPublishResult publishStagedDirectory ( StagedDirectory & staged,
const std::filesystem::path & destination,
const std::filesystem::path & backup )
inline

Renames staged.path to destination. backup is empty when there is no destination, otherwise a free name from uniqueSiblingPath. A rename of a directory over an existing directory fails on Windows, which is why the old destination is moved aside first and moved back when the rename into place fails. When the step is MoveToBackup or Rename staged still owns its directory, so the caller can just return and let the destructor remove it.

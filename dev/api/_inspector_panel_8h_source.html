29// The inspector dock, titled after the selected item. It has one form for each kind of item that the user can select on the canvas: a node, an arc,
30// a connection, a signal and a train. Selecting an item shows its form, fills it in and puts a highlight on the item.
31// Before a run the items are the ones of the track preview, which the form fills in from the scene. During and after a
32// run the items belong to the run and the form fills in from them. The panel keeps what is selected, so that the window
33// can mark the station overlay and the train of the selection.

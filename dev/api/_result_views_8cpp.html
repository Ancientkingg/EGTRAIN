const std::function< std::string()> & provider,
const std::function< bool(const QString &, const std::string &)> & artifactWriter )

Asks for a path and writes CSV text atomically. A cancelled dialog or a failed write never leaves a partial file behind. provider gives the text, and artifactWriter writes it together with its provenance and returns whether it succeeded. Empty text writes nothing and says that there is no data. ".csv" is added to a path without it.

Release rehearsal 2026-10-17¶

Date: 2026-10-16 and 2026-10-17

This record names one candidate and the later candidates that rechecked its defects. It follows the release testing checklist and fills the template.

No release was published, so the rows that need a published release are left to the owner. Left to the owner lists them.

Fixed. Run 39032467694: no path under /opt/homebrew or /usr/local in 39 Mach-O files.

On Windows R9 the cause was the test machine and not the update helper, as far as it could be told. The program of release 1.0.2 fails to start from a staged folder on this machine with the error Insufficient system resources exist to complete the requested service, and it uses about 2 GB of the 4 GB. After a restart of the machine, the same update installed 1.0.2 and left the backup .egtrain-old. Staging also runs a PowerShell unpack with a limit of 60 seconds, which timed out once, and a failed attempt left a hidden .qegtrain-update-* folder behind. #886 gives the unpacking more time and clears failed staging folders. It was merged after run 39032467694. On run 39049264770, which holds it, the portable copy offered EGTRAIN 1.0.2 is Available, prepared the update in about 21 seconds, said The update is ready. EGTRAIN will restart now., and restarted into 1.0.2 at the first attempt, with the backup EGTRAIN.egtrain-old next to it. A hidden .qegtrain-update-* folder holding only the update helper stayed behind: the program that removes it after a restart is the new one, and 1.0.2 predates that cleanup, so this row can show the cleanup only once a newer release is the target.

Other fixes were seen in run 39032467694 on Windows: the clipped text of default buttons (#874) and long case names in the case chooser (#877). In the case chooser, Enter on an unavailable recent case opened another case. That is fixed by #887, merged after the last candidate.

One gap is still open: #883. At 1024 by 768 the toolbar separators change between thin lines and grey blocks with the window width, the zoom buttons drop off the toolbar below about 900 pixels, and the restored window is 1044 by 788, larger than the screen.

Left to the owner¶

These need a published release, a person at the keyboard or a different machine.

  • Row W8, the in-app update of an installed Windows copy. It needs a published release with the installer in its manifest and an older installed Setup.

  • The update test across two published releases, tracked in #405.

  • Row M4 after Open Anyway on macOS: enter the administrator password, then record whether EGTRAIN starts and which dialog, if any, comes next.

  • Row R9 on a physical x64 Windows PC. The virtual machine passed it on run 39049264770.

  • Row W5 with a real older Setup once one is published.

Issue #74 stays open until the owner has decided whether this record, with the rows above, is enough.
